# Repository Agent Checklist

## Local fork notes

- Local sideload signing uses team `Y6SAB8VUS3` and bundle `com.zedle.CloudNow` (not upstream `com.owenselles.CloudNow2`). BG token-refresh id / keychain service use `com.zedle.CloudNow.*`. Prefer `xcodebuild` + `devicectl device install app` over Xcode MCP RunProject for device installs.
- GFN Settings frame-rate eligibility (`GFNSettingsEligibilityPolicy.frameRates`) uses a **membership ceiling**: at the selected resolution, any candidate fps <= max entitled fps is membership-allowed. Display gating via `maximumFramesPerSecond` is unchanged (Apple TV HDMI is typically 60 Hz).
- GFN overlay trigger hold (`OverlayLongPressGesture` in `InputSender.swift`) forwards the trigger to the game live so in-game hold-Start actions work; after 216 ticks (~1.8 s) it opens the local menu and masks the trigger until physical release. A trigger still held when input resumes is `suppressedUntilRelease()`. Xbox (`XboxCloudOverlayGestureState`) still withholds Menu; see TODO.MD. Never install/launch on the user's Apple TV (Bedroom (2)) unless explicitly asked.
- Video presentation (GFN and Xbox share `VideoSurfaceView`): when the display refreshes at <= 30 Hz (measured from `CADisplayLink`), `WebRTCFrameRenderer` routes frames through `DisplayLockedFrameQueue` and enqueues at most one per refresh instead of presenting on arrival; this mode bypasses `AdaptiveFramePacer`. Above 30 Hz the original immediate/paced mailbox path is unchanged. Coverage: `CloudNowTests/Video/DisplayLockedFrameQueueTests.swift`.
- UI theme ("Neon Glass"): `CloudNow/UI/CloudNowTheme.swift` owns colors, `CloudNowBackdrop`, `CloudNowGlowButtonStyle`, `cloudNowGlass`, and `CloudNowSectionTitle`. The provider accent flows through `@Environment(\.cloudNowAccent)` set by `.cloudNowTheme(accent:)` in `CloudNowApp`; the production root forces `.preferredColorScheme(.dark)` (UI-test root still honors `--cloudnow-ui-color-scheme`). The tab-shell backdrop is static (no animation behind streams).
- GFN quality presets: `Session/StreamQualityPreset.swift` (`StreamQualityPresetPolicy.apply`) maps presets to resolution/fps/bitrate/codec/color/chroma plus network adjustment, AI filter, and HUD sharpening, clamped by `GFNSettingsEligibilityPolicy.frameRates`, account resolutions (16:9 preferred), and the TV's output-mode height (`maximumDisplayHeight`, so a 5K entitlement never gets requested on a 4K TV; 5K 4:4:4 caused display evictions at 30 Hz). Build the context with `GamesViewModel.qualityPresetContext`; `normalizeStreamSettingsForCurrentEntitlements` re-applies a saved non-Custom preset when the subscription loads. Presets mirror the native client (REA, GeForceNOW 2.0.90.126): `nativeProfile` ids Custom 0 / Balanced 1 / Competitive 2 / Data Saver 3 / Cinematic 4; Data Saver 720p60 12 Mbps; Cinematic = Optimal Quality + prefilter Auto + HUD. Bitrate range 5-100 Mbps (`minSelectableBitrateKbps` 5000), stepped on the 5 Mbps grid via `GFNBitrateControl.steppedBitrate`; the bitrate row is a `focusSection`. Settings rows use `presetTrackingBinding` so any manual change flips to Custom. UI in `UI/GFNStreamQualityControls.swift`. Coverage: `StreamQualityPresetTests`, UI test `testStreamQualityPresetAppliesAndManualBitrateEditSwitchesToCustom`.
- GFN native streaming features (`Session/GFNStreamingFeatures.swift`): `NetworkAdjustmentMode` (Off 0 / Optimal Latency 1 / Optimal Quality 2, default 1; legacy `adjustForPoorNetwork` Bool decodes true -> 1, false -> 0) drives NVST `a=vqos.dynamicStreamingMode:N` and `a=vqos.drc.enable` (mode != 0; `dfc` stays 0). `VideoPrefilterMode` (Off/Auto/Custom, levels 0-10) and `hudSharpening` go to CloudMatch `requestedStreamingFeatures` (`prefilterMode/Sharpness/NoiseReduction`, `hudStreamingMode` 1 = QP_MAP) and SDP `a=video.prefilterParams.*` when not Off. `enabledL4S` is forced false when network adjustment is Off (native behavior). Entitlements come from MES `features.features[]` (`SUPPORTED_DL_PREFILTERING.setValue`, `HUD_STREAMING`) into `SubscriptionInfo.streamingFeatures`; nil or unreported means not entitled, so only Off is requested and the UI marks the options "not in membership". NVST also sends FEC `repairMinPercent:5`/`repairMaxPercent:40` and `bllFec.enable:1`/`repairMinPercent:5`. Coverage: `GFNStreamControllerTests` (nvstNetworkAdjustment / nvstLossProtection / nvstPrefilterEntitlement), `CloudMatchClientTests.nativeRequestedFeatures`, `MESClientTests.streamingFeatureEntitlements`. Server-side effect is unverified on device (see TODO.MD).
- GFN Jitter Buffer Pacing (`Video/JitterBufferFramePacer.swift`, toggle `StreamSettings.jitterBufferPacing`, default off): port of native `FrameTiming::nextPresentationTimestamp` (offset EMA 2/61, 99.7th-percentile jitter EMA 2/3601 with ±75 ms outlier clamp, advance 20 ms warm-up then clamp 8-32 ms with a 100-frame ramp, RTP 90 kHz, reset on duplicate/backwards ts). `StreamSettings.framePacingMode` picks jitterBuffer > adaptive > immediate; `VideoSurfaceView.setFramePacing` routes frames into `ScheduledFrameQueue` (capacity 7, newest due frame wins). The <= 30 Hz display-locked path still takes priority. Xbox still uses `setAdaptiveFramePacing`. Coverage: `CloudNowTests/Video/JitterBufferFramePacerTests.swift`.
- GFN analog sticks use per-slot `AnalogStickDeadzoneFilter` hysteresis (enter at deadzone, exit at `deadzone * 0.65`) via `mappedControllerState`. Clear stick filters and neutral-reinforce tokens on `detachController`, `stop()`, `applyRemoteMode`, and slot reuse in `attachController`. Overlay tap samples use `mappedControllerState` so mid-band sticks stay consistent. Coverage: `CloudNowTests/Streaming/AnalogStickDeadzoneFilterTests.swift`.

For every task that changes repository content, complete this checklist before reporting the task as finished:

1. Read the pinned SwiftFormat and SwiftLint versions from the `README.md` **Linting** section. The README is the source of truth; do not assume previously installed versions are current.
2. Verify the executables match those exact versions.
3. Run the non-mutating checks from the repository root:

   ```bash
   swiftformat --lint --config .swiftformat CloudNow CloudNowTests CloudNowUITests
   swiftlint --strict --config .swiftlint.yml CloudNow CloudNowTests CloudNowUITests
   ```

4. Do not mark the task complete until both checks pass. If a local executable has the wrong version, use the pinned CI/pre-commit tool environment instead of running the mismatched executable.
5. Report both check results in the final response.
